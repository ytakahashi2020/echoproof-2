# EchoProof — 1-minute pitch script

**0:00-0:15**

Environmental and urban data is expensive to collect at scale. Existing datasets are often centralized, stale, or impossible to verify. This is a real problem for cities and researchers.

> 環境データや都市データを大規模に収集するにはコストがかかります。既存のデータセットはしばしば中央集権的で、古く、検証が困難です。これは都市や研究者にとって実際の課題です。

**0:15-0:30**

EchoProof solves this by turning everyday smartphones into a DePIN network. Users passively capture noise, air quality, light, and GPS-tagged data.

> EchoProofは、身近なスマートフォンをDePINネットワークに変えることでこれを解決します。ユーザーは騒音、空気質、照度、GPS付きデータを受動的に収集します。

**0:30-0:45**

Each reading is signed with device attestation and proven on Solana. Anti-spoofing checks protect data quality, and honest contributors earn SOL and token rewards.

> 各データはデバイスアテステーションで署名され、Solana上で証明されます。不正検知の仕組みがデータ品質を守り、正直な貢献者はSOLとトークン報酬を獲得します。

**0:45-0:55**

City planners, researchers, and insurers can then query these verified datasets by region and time, paying per query through Solana Pay.

> 都市計画者、研究者、保険会社は、地域と期間で検証済みデータセットを検索し、Solana Payでクエリごとに支払うことができます。

**0:55-1:00**

EchoProof makes trustworthy environmental data accessible, verifiable, and rewarding for everyone. This is DePIN in action on Solana. Thank you.

> EchoProofは、信頼できる環境データをアクセスしやすく、検証可能で、報酬のあるものにします。これはSolana上で実現するDePINです。ありがとうございました。
